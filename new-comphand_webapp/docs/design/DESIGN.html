KBank Indonesia UI/UX Design System

This document serves as the foundational HTML/CSS reference for the KBank Indonesia frontend architecture.

1. Core Color Palette

KBank Green #00A94F
ID Gradient #008F62 to #00F88E
Merchant Red #EC1C24
Secondary Red #D01920
Light Gray #E0E0E0
Black #333333

2. Typography Rules

Primary Font: Kurious Looped Cond [cite: 919, 920, 921]

Casing Constraints: Always typeset text in title case or sentence case. Do not set in all caps or all lowercase. [cite: 937, 940, 942, 943, 944, 947]

Hierarchy Option A (Default)

Uses SemiBold for Headings and Regular for Body Text. [cite: 957, 958, 959, 960, 961]

Hierarchy Option B (Alternative)

Uses Medium for Headings and Light for Body Text. [cite: 970, 971, 972, 973]

3. Component Styling Constraints

  • Clear Space: Maintain 0.5X padding around core elements (represented as var(--clear-space) in CSS). [cite: 152, 165, 179]
  • Visual Effects: Drop shadows and outlining are strictly prohibited. [cite: 202, 208, 236, 246]
  • Opacity: Modifying the transparency of primary brand symbols is not allowed. [cite: 214, 254]
