# KBank Indonesia - UI/UX Design System Guidelines

## 1. Core Color Palette
* [cite_start]**KBank Green (Primary Interactive/Brand):** Hex `#00A94F`[cite: 349, 352]. [cite_start]RGB: 0, 169, 79[cite: 356].
* [cite_start]**ID Gradient (Accents):** Hex `#008F62` to `#00F88E`[cite: 350, 353, 357].
* [cite_start]**White (Backgrounds/Neutral):** Hex `#FFFFFF`[cite: 351, 358].
* [cite_start]**Black (Primary Text):** Hex `#333333`[cite: 359, 360].
* [cite_start]**Merchant Red (Alerts/Destructive Actions):** Hex `#EC1C24`[cite: 361, 362]. [cite_start]RGB: 237, 27, 46[cite: 365].
* [cite_start]**Secondary Red:** Hex `#D01920`[cite: 437].
* [cite_start]**Light Gray (Borders/Secondary Backgrounds):** Hex `#E0E0E0`[cite: 428, 429].

## 2. Typography Rules
* [cite_start]**Primary Font Family:** Kurious Looped Cond[cite: 919, 920, 921].
* [cite_start]**Permitted Font Weights:** Light, Regular, Medium, SemiBold[cite: 923, 925, 927, 929].
* [cite_start]**Casing Constraints:** Always typeset text in title case or sentence case[cite: 942]. [cite_start]Do not set text in all uppercase or all lowercase letters[cite: 939, 943, 947].
* [cite_start]**Hierarchy Pairing:** * *Option A:* Use SemiBold for Heading Text paired with Regular for Body Text[cite: 958, 959, 960, 961].
    * [cite_start]*Option B:* Use Medium for Heading Text paired with Light for Body Text[cite: 971, 972, 973].

## 3. Spacing and Component Styling
* [cite_start]**Clear Space (Padding/Margin):** Maintain strict clear space equal to 0.5X (half the height of the capital "K") around all core branding elements and primary components[cite: 159, 174].
* [cite_start]**Visual Effects Restrictions:** Do not apply drop shadows, outline borders, or any other rendering effects to brand elements[cite: 202, 208, 219, 236].
* [cite_start]**Opacity:** Do not alter the transparency of core elements[cite: 214, 254]. 
* [cite_start]**Contrast Requirements:** Ensure UI elements are placed on clean, uncluttered backgrounds providing sufficient color contrast for optimal visibility[cite: 857].
